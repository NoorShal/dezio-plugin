# Trustfactory website builder for Claude Code

Build and manage websites on Trustfactory's Website Studio from Claude Code: the Studio's tools, the design and
writing guides, and a helper that keeps a site's design folder in step with the Studio.

## Install

In Claude Code (the terminal, or the desktop app's Code tab):

```
/plugin marketplace add NoorShal/trustfactory-website-builder
/plugin install trustfactory-website-builder@trustfactory
```

It asks once for your Studio key: make one in the Studio under **Agent keys**. The key is kept in your computer's
keychain.

## Use

Ask for what you want, for example:

> Build a website on Website Studio for my car wash. Interview me first.

## Updates

```
/plugin marketplace update trustfactory
```

This repository is a published copy; the plugin is developed and tested together with the Studio.
Third-party rules it builds on are credited in `trustfactory-website-builder/THIRD-PARTY.md`.
